### Featured Work

**Automotive Cybersecurity**
Hands-on labs and notes covering symmetric/asymmetric cryptography, hashing and MACs, digital certificates, and the AUTOSAR Crypto Stack (CSM, CryIf, Crypto Driver, HSM/SHE). Also covers secure onboard communication, secure storage, secure diagnostics, secure flashing, and secure boot — with practical OpenSSL examples and encryption/decryption scripts.
